## Featured Projects
 
### [RaftDB](https://github.com/bhattt1/RaftBasedDistributedKey)
A distributed key-value database built on the Raft consensus algorithm in Go. Implements leader election, log replication, linearizable reads, exactly-once semantics, crash-safe WAL with CRC-32C checksums, and mutual TLS. Tested with deterministic simulation (FoundationDB-style), Porcupine linearizability checking, and fault injection across 2M+ verified operations.
 
`Go` `gRPC` `Raft` `Protobuf` `Prometheus` `Docker`
 
### [ShopSphere](https://github.com/bhattt1/shopsphere)
A microservices e-commerce platform with 5 services, 35 REST APIs, and event-driven order processing. Features JWT/RBAC authentication, Apache Kafka with SAGA and compensating transactions, Transactional Outbox pattern, Redis session management, and Stripe payment integration.
 
`Java` `Spring Boot` `Angular` `Kafka` `Redis` `PostgreSQL` `Docker`
 
### [WorkForcePro](https://github.com/bhattt1/WorkForcePro)
An enterprise workforce management API built with ASP.NET Core, Clean Architecture, and CQRS. Implements domain separation across bounded contexts with EF Core, JWT authentication, and claims-based authorization.
 
`C#` `ASP.NET Core` `Angular` `MSSQL` `EF Core` `CQRS`
